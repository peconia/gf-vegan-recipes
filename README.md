# Gluten free vegan recipes

This is a collection of recipes, less about the coding and more about storing things that work for me.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, install the dependenices:

```bash
asdf install

npm i
```

Then, run the development server:

```bash
npm run dev

```

Open [http://localhost:3000/gf-vegan-recipes](http://localhost:3000/gf-vegan-recipes) with your browser to see the result.
